# Finnish site release · 13 November 2026

This release publishes the accumulated local Finnish-site improvements, following the owner's explicit publication request.

- Search: in-place suggestions, short and long Finnish queries, typo handling, calendar dates, cities and targeted tool results.
- Planning tools: calendar studio, holiday calendar actions, date and working-day calculations, shift planning, education filters and year-organized PDF catalogs.
- Content and presentation: Finnish services, topic photographs with recorded credits, responsive navigation and form layouts.
- Privacy: Finnish policy pages and controls for inspecting, exporting and selectively deleting this site's browser data. No browser analytics configured in Cloudflare Pages at release preparation.

Validation before publication: 102 Node tests and 19 Python tests passed. Full production build generated 1,269 pages. The build audit checked 2,273 entries, including 1,004 PDF files and 1,004 WebP files, with no failures. Targeted desktop/mobile interaction and accessibility checks are recorded in the external working report directory.

The publication is verified separately by matching the live release commit, testing public endpoints and opening production pages. Local benchmark results do not represent guaranteed public performance. Legal controller address was not supplied; no address, professional review or indexing guarantee is invented.
